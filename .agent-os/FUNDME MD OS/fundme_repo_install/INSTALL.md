# Install the Fundme Project OS

Copy this pack into the Fundme repository root, preserving paths.

Start every new agent session with:

1. `PROJECT_STATE.md`
2. `FUNDME_PROJECT_OS.md`
3. `AGENTS.md`
4. `docs/phases/PHASE_01_BUILD_CONTRACT.md` or the current phase contract
5. the relevant specialist document under `docs/`

Before implementation, the first agent must audit the current repository and update `PROJECT_STATE.md` where the repository differs from the documented assumptions.
