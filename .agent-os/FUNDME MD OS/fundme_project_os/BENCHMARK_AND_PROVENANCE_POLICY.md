# Benchmark and Provenance Policy

## Purpose

The assessment must be informed by credible funding and application patterns without misrepresenting unverified material as “winning.”

## Permitted initial sources

- official accelerator criteria
- official accelerator application guidance
- official public investor and pitch guidance
- public program FAQs
- public pitch decks where usage is lawful
- founder-published application examples
- explicitly permissioned applications
- annotated synthetic cases
- FundMe-authored methodology

## Prohibited or restricted

- leaked private applications
- scraped restricted profile data
- confidential investor documents
- examples with unknown provenance presented as accepted
- copyrighted collections copied wholesale
- material whose usage rights are incompatible with the product

## Required metadata

Every corpus entry must record:

- stable ID
- title
- publisher/owner
- source
- source type
- access date
- verification date
- permission/license
- claimed outcome
- outcome verification status
- category
- stage
- geography
- notes

## Language rules

Allowed:

- “official YC application guidance”
- “public founder-published example”
- “synthetic annotated example”
- “accepted outcome verified through [source]”

Not allowed without proof:

- “winning application”
- “what YC wants”
- “guaranteed investor pattern”
- “funded founder profile”

## Evaluation use

Benchmark material may:

- inform scoring definitions
- support recommendations
- provide examples
- guide follow-up questions
- help calibrate human review

It must not:

- override founder evidence
- decide eligibility without rules
- silently change the rubric
- create unsupported causal claims
