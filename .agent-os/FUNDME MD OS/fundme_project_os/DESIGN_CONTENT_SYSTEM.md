# Design, Content, and Brand System

> Status: Canonical unless marked otherwise  
> Product: Fundme  
> Last updated: 2026-06-21  
> Production baseline: `main` at `c363eb2`, live at `https://tryfundme.in`  
> Rule: Repository and production behavior override stale documents.


## Brand character

Founder-grade, editorial, honest, operational, and sharp. Fundme should feel credible enough for a serious application decision and fast enough for a solo founder.

## Existing visual anchors to preserve

- Warm cream background.
- Orange flame accent.
- Dark primary actions.
- Serif display moments paired with readable sans-serif UI text.
- Serious tone, not playful gamification.

## Design priority

1. Comprehension.
2. Trust.
3. Progress.
4. Actionability.
5. Speed.
6. Visual distinctiveness.

Cosmetic novelty is last.

## Component behavior

- Every CTA has a real action and clear state.
- Disabled controls look disabled and explain why where necessary.
- Loading states describe actual work.
- Empty states lead to the next action.
- Error states preserve entered data.
- Cards should summarize decisions, not merely decorate content.
- Tables must work on mobile through responsive patterns, not horizontal chaos.
- Public pages favor readable content; application workspaces favor dense operational UI.

## Assessment presentation

- Use bands and evidence, not false decimal precision.
- Show strongest signal, largest blocker, and next action first.
- Distinguish missing evidence from weak performance.
- Never represent demo content as personalized analysis.

## Copy rules

- Say what the product actually does now.
- No guaranteed funding or acceptance claims.
- Avoid inflated AI language.
- Prefer verbs: assess, improve, match, draft, track.
- Explain uncertainty directly.
- One CTA should dominate a page.
- Avoid internal implementation terms in user-facing copy.

## Naming

Canonical product name: **Fundme**.

Use `Fundme` in navigation, product UI, and primary copy. Use `tryfundme.in` only as a domain. Avoid switching among Fundme, Fundme.ai, and GetFunded in product surfaces unless a formal brand decision changes this document.

## Accessibility

- Keyboard navigation.
- Visible focus.
- Semantic headings and landmarks.
- Form labels and errors.
- Sufficient contrast.
- Motion respects reduced-motion preference.
- No information conveyed by color alone.
- Screen-reader announcements for async progress and errors.

## Responsive baseline

- 390px mobile acceptance required.
- Touch targets at least practical mobile size.
- No clipped fields, tables, or footer content.
- Avoid large decorative type that obscures the core action.

## Redesign freeze

A broad website redesign is not a phase deliverable before the functional product loop is complete. Incremental design improvements are permitted when tied to measurable usability, trust, accessibility, or conversion outcomes.
